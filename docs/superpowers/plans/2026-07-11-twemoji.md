# Twemoji Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render emojis in user-authored content as consistent, self-hosted flat Twemoji SVGs instead of native OS emoji.

**Architecture:** `@twemoji/api`'s `parse()` walks a DOM element's text nodes and swaps emoji codepoints for `<img class="emoji" src="/twemoji/svg/<codepoint>.svg">`. The SVGs come from the `@twemoji/svg` npm package, copied into the app's served `public/twemoji/svg/` at build via `vite-plugin-static-copy` (self-hosted, no CDN). A global Vue directive `v-twemoji` runs `parse()` on content-container elements after render.

**Tech Stack:** Laravel 13 + Inertia v3 + Vue 3 (client-only, no SSR), Vite 7, Tailwind v4, Pest 4 (browser plugin available). Served by Herd at `https://taylordrayson.test`.


- [ ] **Step 2: Configure the asset copy in `vite.config.js`**

Add the plugin so the SVGs land in the Herd-served `public/twemoji/svg/`. Import at top:
```js
import { viteStaticCopy } from 'vite-plugin-static-copy';
```

```js
        viteStaticCopy({
            targets: [
                {
                    // Serve Twemoji's SVGs from our own origin at /twemoji/svg/*.
                    src: 'node_modules/@twemoji/svg/*.svg',
                    dest: 'twemoji/svg',
                },
            ],
        }),
```

Choose the configuration that makes the assets reachable at the app origin and set the `base` in Task 2 to match:
- Preferred: land the files at `public/twemoji/svg/` (served at `/twemoji/svg/`) so `base: '/twemoji/'`. If `vite-plugin-static-copy` cannot target outside `outDir` cleanly, EITHER set `base` to wherever the files actually land (e.g. `/build/twemoji/`), OR add the copy to `public/twemoji/` a way that persists for both dev and build.

### Task 2: `v-twemoji` directive + timeline application + browser test

**Files:**
- Create: `resources/js/directives/twemoji.js`
- Modify: `resources/js/app.js` (register the directive globally)
- Modify: `resources/css/app.css` (the `img.emoji` sizing rule)
- Modify: `resources/js/Components/Timeline/FeedItem.vue` (apply `v-twemoji`)
- Test: `tests/Browser/TwemojiTest.php`

**Interfaces:**
- Consumes: the served SVG base from Task 1.
- Produces: a global `v-twemoji` directive usable as `<el v-twemoji>`; emoji glyphs inside become `<img class="emoji">`.

- [ ] **Step 1: Write the directive**

Create `resources/js/directives/twemoji.js`:
```js
import twemoji from '@twemoji/api';

// Twemoji options: resolve each emoji to our self-hosted SVG (set base to the
// path confirmed in Task 1) rather than the default jsDelivr CDN.
const options = {
    base: '/twemoji/',
    folder: 'svg',
    ext: '.svg',
    className: 'emoji',
};

// Replace native emoji glyphs in the element's subtree with Twemoji <img>.
// parse() is safe to re-run on update: it skips text already inside its
// generated <img>, so reactive/deferred content re-parses cleanly.
function apply(el) {
    twemoji.parse(el, options);
}

export const twemojiDirective = {
    mounted: apply,
    updated: apply,
};
```
> Set `base` to the exact served path Task 1 reported (e.g. `/twemoji/` or `/build/twemoji/`).

- [ ] **Step 2: Register it globally in `app.js`**

In `resources/js/app.js`, inside `setup({ el, App, props, plugin })`, register before mount:
```js
import { twemojiDirective } from './directives/twemoji';
```
```js
        createApp({ render: () => h(App, props) })
            .use(plugin)
            .directive('twemoji', twemojiDirective)
            .mount(el);
```

- [ ] **Step 3: Add the `img.emoji` sizing rule to `app.css`**

In the `@layer base` block of `resources/css/app.css`, add:
```css
    img.emoji {
        display: inline-block;
        height: 1em;
        width: 1em;
        margin: 0 0.05em 0 0.1em;
        vertical-align: -0.1em;
    }
```

- [ ] **Step 4: Apply the directive to the timeline card text**

In `resources/js/Components/Timeline/FeedItem.vue`, add `v-twemoji` to the three user-text elements: the body `<p>` (`{{ body }}`), the title `<component>` (`{{ title }}`), and the meta `<p>` (`{{ meta }}`). Example for the body:

- [ ] **Step 5: Write the browser test (write first, expect fail before Step 4 is built — but since Step 4 ships in this task, run after)**
