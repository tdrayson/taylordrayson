We rebuilt the entire website

<a href="https://season-3.thisweekwith.co.uk">https://season-3.thisweekwith.co.uk</a>

Moved from Divi to Oxygen

Reasons for the rebuild:

We didn't know how long we would be doing This Week With, so didn't really plan for the future

Being able to search for content was impossible

The design was a pre-designed template

Decided to build a custom design

Looked on <a href="https://www.pinterest.co.uk">Pinterest</a> and <a href="https://dribbble.com">Dribbble</a> for inspiration

Mocked it up on <a href="https://www.figma.com">Figma</a> as a collaborative process

Created three-page designs - home page, archive page (all episodes) and the individual page (single episode)

Built with <a href="https://oxygenbuilder.com">Oxygen Builder</a>

Convert all data from old site to new site:

Change all episode names to new format S2E38

Changed all show notes from a list to paragraphs

Converted all m4a audio episodes to mp3 format for the new site audio player

Link up all the new audio files to the correct episode

Changed every episode image to show the season, as well as the youtube episode thumbnail images

Then went through and linked up all the new graphics everywhere

Edited all youtube videos by removing the countdown timer

Updated the image of Gordon everywhere, so the cut out was much better

New techniques and skills learnt

Now you can:

Search for content, filter episodes by length, season or date using Ajax (immediate updates without reloading the page)

You can then sort by Latest, Oldest, Longest and Shortest episodes

Tooltips show you what an icon is for

Easter eggs (hidden surprises) in the website (watch episode for full details)
