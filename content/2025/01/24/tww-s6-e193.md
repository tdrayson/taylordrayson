Splitting up projects into manageable tasks - quite time consuming to do

Action Hub - a web app designed to do this automatically

Paste specs and notes and return in JSON format the various tasks which are then added to Motion via the API

Ability to set time and bulk edit as required before exporting to the project manager

Using tool - <a href="https://bolt.new/">https://bolt.new/</a>

Uses AI to build a native web app with the UI you specify which can then be moved to your own hosting

Work with React, NextJS, and all the modern languages, and connects to Supabase database service - <a href="https://supabase.com/">https://supabase.com/</a>

Easy to update and make changes

Open-AI API key usage

Making Good Documentation

Panto is all finished and this week I edited the videos

Two full shows needed editing this year

Uploading to three services for redundancy

Then added to Drayson Design Videos service

Don't use this all the time, so I need good documentation to remind me what steps to take

Documenting processes is really important for many reasons - written, video, whatever works for you
