Join me for this episode of Talk Devy To Me as we dive into WP Wireframe, a PHP framework for building JavaScript-powered WordPress admin interfaces with my guest Taylor Drayson.

Here's the hook: there's no build process. You write all your configuration in PHP and WP Wireframe generates the JavaScript admin for you: no webpack, no compile step, no npm run build. We'll dig into how Taylor pulled that off, why skipping the build step matters for WordPress developers, and then put it through its paces building something live.
